# ChatGPT y Codex para FP de Ciencias Sociales

Web del curso online «ChatGPT y Codex para la coordinación académica y la docencia en FP de Grado Superior (Ciencias Sociales)».

- 8 módulos con contenidos, ejercicios paso a paso, prompts copiables y entregables.
- Seguimiento del progreso por módulo (se guarda en el navegador de cada participante).
- Tablas filtrables de herramientas, conectores y plugins.
- Glosario: plugin, conector, servidor MCP y skill.
- Evaluación, ética y recursos.

## Editar el contenido

Todo el texto del curso está en [`data/curso.ts`](data/curso.ts). Al cambiarlo y subirlo a GitHub, Vercel vuelve a desplegar la web automáticamente.

## Desarrollo local

```bash
npm install
npm run dev
```

Abre http://localhost:3000.

Hecho con Next.js 15 y desplegado en Vercel.
